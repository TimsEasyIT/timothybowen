# Timothy Bowen IT Portfolio

This is a responsive static portfolio website designed for GitHub Pages.

## Main files

- `index.html` — homepage
- `css/styles.css` — site styling
- `js/main.js` — mobile navigation and automatic copyright year
- `projects/` — reusable project detail pages
- `assets/images/` — screenshots and diagrams
- `assets/documents/` — résumé PDF and other downloadable files
