# Timothy Bowen IT Portfolio

This is a responsive static portfolio website designed for GitHub Pages.

## Main files

- `index.html` — homepage
- `css/styles.css` — site styling
- `js/main.js` — mobile navigation and automatic copyright year
- `projects/` — reusable project detail pages
- `assets/images/` — screenshots and diagrams
- `assets/documents/` — résumé PDF and other downloadable files

## Before publishing

1. Replace all placeholder text.
2. Update the email and LinkedIn URLs in `index.html`.
3. Add your résumé as:
   `assets/documents/timothy-bowen-resume.pdf`
4. Add project screenshots to `assets/images/`.
5. Review each project page and remove sections you do not need.
6. Commit the files to your GitHub Pages repository.

## GitHub Pages

Upload the contents of this folder to the root of the repository currently
publishing `timothybowen.net`.
